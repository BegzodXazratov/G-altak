# Qal'a jangi 1150

12-asr Angliyasidagi qal'a qamali haqida brauzer 3D strategiya o'yini. Bir tomon qal'ani quradi va himoya qiladi, ikkinchisi zaif nuqtani topib egallaydi. Har ikki tomonda 120 tanga.

- `index.html`, `css/`, `js/` — o'yin (build kerak emas, oddiy statik sayt)
- `js/sim.js` — jang qoidalari, `js/bot.js` — bot, `js/gfx.js` — 3D sahna, `js/main.js` — boshqaruv
- `assets/models.*` — oldindan tayyorlangan 3D modellar

## Modellar

3D modellar: [KayKit](https://kaylousberg.com) — Adventurers Character Pack va Medieval Hexagon Pack, muallif Kay Lousberg, litsenziya CC0.
3D kutubxona: three.js (MIT).
