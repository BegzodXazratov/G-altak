# Tashkent City 3D

Tashkent City (Toshkent) bo'ylab brauzerda 3D sayr. Hudud chegaralangan, faqat ichida yurish mumkin.

- `index.html`, `js/world.js` (shahar qurilishi), `js/main.js` (o'yinchi, boshqaruv, xarita)
- `assets/city.json` — binolar, yo'llar, maysazor, suv va daraxtlar (siqilgan format, metrda; markaz 41.3163 N, 69.2515 E)
